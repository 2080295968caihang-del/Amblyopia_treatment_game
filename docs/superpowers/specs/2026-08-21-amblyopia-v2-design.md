# Amblyopia_treatment_game v2.0 设计文档

> 日期：2026-08-21
> 状态：已通过 brainstorming 确认，待实现
> 关联：v1.0（单文件 snake_game.html，GitHub 已发布）

## 一、背景与目标

v1.0 为单文件贪吃蛇弱视治疗游戏（遮盖疗法 + 红光闪烁 + CAM 光栅 + 精细目力，背景含颜色/形状/闪烁变化）。v2.0 在保留全部治疗功能基础上：

1. 改为**多游戏架构**：游戏挑选菜单 + 共享背景引擎，当前仅实现贪吃蛇，预留扩展接口。
2. 修复**游戏中无法打开菜单**的问题：新增 `Esc` 游戏菜单。
3. 优化**背景刺激**：删减模式、平滑过渡、更快配色、更明显闪烁。
4. 优化**游戏元素画风**：去像素化，改为高辨识度简约扁平风格。
5. 项目名统一为 **Amblyopia_treatment_game**（GitHub 仓库已同名，本地文件夹已改名）。

## 三、文件结构与架构

```text
Amblyopia_treatment_game/
├── index.html            # 游戏挑选菜单页 + 家长设置入口 + ?test=1 自测
├── css/style.css         # 公共样式（菜单/HUD/设置抽屉/游戏屏幕/主题变量）
├── js/bg-engine.js       # 共享背景引擎（模式/过渡/配色/闪烁），暴露全局 window.BgEngine
├── js/snake.js           # 贪吃蛇游戏 v2（核心纯逻辑 + DOM 接线），暴露 window.SnakeGame
├── docs/
│   └── superpowers/specs/2026-08-21-amblyopia-v2-design.md   # 本文档
├── verify_snake.js       # Node 无头自测（合并加载 js 后跑）
└── acceptance_check.js   # 静态检查 + DOM 桩冒烟验收
```

**加载顺序（index.html）**：`css/style.css` → `js/bg-engine.js` → `js/snake.js` → 内联初始化脚本。

**架构约定**：
- 全部使用普通 `<script>`（非 ES Module），保证 `file://` 双击可运行、零依赖、无构建步骤。
- 全局命名空间：`window.BgEngine`、`window.SnakeGame`、`window.App`（菜单/路由/设置）。
- 背景引擎与游戏解耦：游戏不关心背景具体模式，只负责在每帧把背景实例的 `draw(now)` 与自身 `render(now)` 依次执行；背景引擎内部管理模式轮换、过渡、配色、闪烁。
- 新增游戏步骤（预留）：新建 `js/<game>.js` 暴露 `create(canvas, bgCanvas, settings)` 接口，在 `index.html` 菜单注册一张卡片，无需改动背景引擎。

## 五、共享背景引擎（js/bg-engine.js）

### 5.1 模式集（4 种，与 v1.0 同款绘制思路）
- `red_flicker` 红光闪烁：全屏红黑交替，自带闪烁（不叠加全局闪烁层）。
- `cam_grating` CAM 光栅：旋转黑白条栅，条宽 40–80px 抖动。
- `checkerboard` 棋盘格：黑白棋盘格。
- `stripes` 对比条纹：方向随机（水平/垂直/对角）的对比条纹。

删除：`dots`（圆点阵列）、`fun_shapes`（童趣图案）。勾选面板只显示保留的 4 种，历史 localStorage 中的旧模式索引需兼容（越界/未知索引回退默认）。

### 5.2 切换与过渡
- 每 **15 秒**（固定）切换下一个模式（不重复上一次；全关时走纯色填充路径）。
- 切换过程 **1 秒淡入淡出**：新旧两帧按 alpha 交叉淡化，过渡期间几何按各自种子稳定绘制，避免跳动。
- 过渡采用"双图案 alpha 合成"：`phase ∈ [0,1]`，前 0.5s 旧图案淡出、后 0.5s 新图案淡入，中间交汇。

### 5.3 配色轮换
- 配色独立于模式，每 **5–8 秒**（随机区间）轮换一组高对比色（沿用 v1.0 的 4 组高对比 + 混合模式点缀色池）。
- 轮换同样做 1 秒平滑过渡，避免跳变。
- 配色模式设置：高对比 / 混合（带彩色点缀）。

### 5.4 闪烁
- 三档 **1.2 / 2 / 3.2 Hz**（±20% 抖动），家长设置可选，替换 v1.0 的 0.95/1.4/2.4。
- `red_flicker` 模式自带闪烁；其余模式由引擎叠加闪烁层（明暗交替，强度比 v1.0 更明显——提升 alpha 对比区间）。
- 颜色/形状/闪烁三个独立开关语义保留。

### 5.5 引擎 API
```js
window.BgEngine = {
  create(canvas, settings) -> { start(), stop(), pause(), resume(), draw(now), applySettings(settings), dispose() }
}
```
- `draw(now)`：内部按当前模式/过渡/配色/闪烁绘制一帧；`applySettings` 即时生效（模式勾选、配色模式、闪烁档位、三开关）。
- 尺寸：由外层 `applyResponsiveLayout` 统一维护 canvas 分辨率（DPR 整数格 + MAX 封顶），引擎不负责改尺寸。
- 暂停/恢复：暂停冻结相位，恢复接续，避免相位跳变（沿用 v1.0 语义）。

## 六、贪吃蛇游戏 v2（js/snake.js）

### 6.1 保留自 v1.0（已验证）
- 核心纯函数：`createInitialState / stepGame / isWallCollision / isSelfCollision / randomFoodCell / speedForLevel / initialSpeedMs / setDirection / steerByMouse / handleGameKey / togglePause` 等（Node 可测，`?test=1` 自测与 verify 脚本继续使用）。
- 输入：方向键 / WASD 键盘 + 鼠标跟随（按住左键锁定，键盘可覆盖）。
- 速度：每吃 5 个升一档，起始速度家长可调 1–5 档，封顶 7 档。
- 音效：Web Audio 合成（吃食物"叮"880Hz、结束 220→110Hz 下滑），可静音。
- 最高分与设置持久化：`localStorage`（沿用键名）。
- 遮眼提醒：开始页 + HUD 常驻。

### 6.2 画风升级（G 简约扁平）
- 蛇：每节大圆角矩形（圆角 ≈ 1/3 边长），头部亮绿色、身体深绿色渐变，头部画白底黑瞳大眼睛；整体不透明大色块、清晰轮廓。
- 食物：大红色圆形果实 + 顶部绿色叶片 + 白色高光点，尺寸比 v1.0 方块更大（视觉占比提升，便于弱视辨识）。
- 游戏 canvas 底板透明（背景由底层背景引擎绘制），蛇与食物叠加其上，并绘制深色外轮廓 + 浅色内描边，确保在任何背景色下都高对比清晰。

### 6.3 Esc 游戏菜单（新增）
- 游戏中按 `Esc`（或暂停按钮）弹出半透明遮罩菜单：**继续 / 设置 / 重新开始 / 返回游戏列表**。
- 打开菜单即暂停游戏（与空格/P 共用 `state.paused` 语义，背景相位冻结）。
- "设置"项打开家长设置抽屉（游戏保持暂停）；关闭抽屉回到游戏菜单。
- "返回游戏列表"停止游戏与背景，回到 index.html 菜单页。

### 6.4 HUD
- 分数 / 最高分 / 速度档 / 遮眼提示 / 暂停按钮 / 静音按钮。

## 七、家长设置（菜单页与游戏内共用）

- 抽屉组件（`index.html` 内联实现，供菜单页与游戏内复用）：
  - 闪烁档位：1.2 / 2 / 3.2 Hz（单选）
  - 刺激模式勾选：红光闪烁 / CAM 光栅 / 棋盘格 / 对比条纹（4 项，至少保留一项；全关时纯色路径）
  - 配色模式：高对比 / 混合（带彩色点缀）
  - 起始速度：1–5 档
  - 音效开关
  - 背景变化三开关：颜色变化 / 形状变化 / 闪烁
- 变更即时生效并写入 `localStorage`（键沿用 `amblyopia_snake_settings_v1`，兼容 v1.0 已存数据：模式数组长度按新 4 项映射，越界回退默认）。
- 底部建议文案："建议每次 10–15 分钟、每天 1–2 次；请遵医嘱；训练时遮盖好眼"。

## 八、自适应与平板 WebView 预留

- `viewport` 含 `viewport-fit=cover`；safe-area 缩进保持单层（容器层）。
- 棋盘尺寸：`computeBoardSize`（min(视口宽, 高-预留) 取整到网格整数倍 + 封顶）与 DPR 分辨率逻辑保留，抽到公共层（`bg-engine.js` 或独立 `js/common.js`）供菜单/游戏共用。
- 触控处理器在 snake.js 中预留（`handleTouchStart/Move/End`），供后续 Capacitor WebView 填充。

## 九、验证策略

- `verify_snake.js`：合并加载 `bg-engine.js` + `snake.js`（+ 内联自测），在 Node 无头环境运行纯函数自测；预期全部 PASS（数量以最终实现为准，不少于 v1.0 的 128 项）。
- `acceptance_check.js`：静态检查（文件结构、无外链、关键功能锚点）+ DOM 桩冒烟（菜单→进游戏→Esc 菜单→设置→返回菜单全流程、持久化、背景模式配置、画风锚点）。
- 浏览器 `?test=1`：在页面加载后运行自测并显示结果横幅。
- 关键新增验收项：
  1. 菜单页显示贪吃蛇卡片与 2 张占位卡片；
  2. 游戏中按 `Esc` 弹出菜单，含继续/设置/重新开始/返回游戏列表；
  3. 背景引擎：4 模式、15s 切换、1s 过渡、5–8s 配色、1.2/2/3.2Hz 闪烁；
  4. 画风：蛇为圆角色块 + 眼睛，食物为大果 + 叶（非纯像素方块）；
  5. 多文件 `file://` 双击可运行，无外链依赖。
