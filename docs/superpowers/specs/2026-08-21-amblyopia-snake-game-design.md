# 弱视治疗贪吃蛇游戏 设计文档

- 日期：2026-08-21
- 项目目录：Amblyopia_Treatment
- 目标文件：snake_game.html（单文件，零依赖）
- 状态：已获用户确认

## 一、背景与目标

原项目 busy-eye 是一个弱视训练书签脚本（网页叠加黑白棋盘格）。用户反馈其效果不符合预期，希望改为「以贪吃蛇游戏的形式进行治疗」，面向低龄弱视儿童。目标：孩子边玩贪吃蛇，边接受基于公认疗法的视觉刺激训练。

## 二、医学依据（公认疗法）

- **遮盖疗法**：训练时必须遮盖好眼，只用弱视眼看（每日 2–6 小时属常见遮盖时长，训练期间不可偷看）。
- **红光闪烁刺激**：630–660nm 红光、低频闪烁（常见设备档位约 0.95Hz / 1.4Hz / 2.4Hz），刺激黄斑中心区；常规每次 10–15 分钟。
- **CAM 光栅刺激**：高对比黑白方波光栅旋转/移动，孩子同时执行需要视觉注意力的任务。
- **精细目力训练**：追辨高对比、变化形状/颜色的食物，本身就是精细辨视任务。
- 工具定位：**辅助训练**，不能替代正规医疗；建议每次 10–15 分钟、每天 1–2 次，并遵医嘱。

## 三、交付形式与技术约束

- 单文件 `snake_game.html`（HTML + CSS + JS 全部内嵌），放置于 `Amblyopia_Treatment\`，保留原 busy-eye 文件。
- 零依赖、离线可用，桌面浏览器双击即玩（`file://` 协议兼容）。
- WebView 兼容预留：不使用仅限浏览器的特性，布局自适应窗口/平板比例，触控接口预留。
- 后续平板落地：用 Capacitor 封装 WebView 生成安卓 APK（本次不搭建工程，仅保证页面兼容）。

## 四、界面与流程

1. **开始页**：游戏标题、遮眼提醒（"请先遮盖好眼，只用弱视眼看"）、最高分显示、「开始游戏」「家长设置」按钮。
2. **游戏中**：顶部 HUD（分数、最高分、当前速度档、暂停/静音按钮），中央为棋盘；顶部常驻"遮盖好眼"小提示。
3. **暂停**：空格 / P 键，或点击暂停按钮。
4. **结束页**：本次分数、最高分（localStorage 记忆）、「再玩一次」按钮。

## 五、背景刺激层（核心）

三层渲染：刺激背景层（独立 canvas）→ 游戏层（蛇/食物）→ HUD/UI。

- **6 种刺激模式**，默认全部参与随机轮换，每 20–40 秒切换一次（家长可勾选子集）：
  1. 红光闪烁：红色高对比背景，按档位频率交替闪烁
  2. CAM 光栅：高对比黑白方波条纹（横/竖/斜随机），缓慢旋转/平移
  3. 棋盘格跳动：高对比棋盘格，整体微平移跳动
  4. 圆点阵列：高对比圆点阵列（大小随机）
  5. 对比条纹：粗细变化的对比条纹
  6. 童趣图案：星星/花朵/爱心/月亮，高对比配色随机排列
- **颜色变化**：高对比配色组自动轮换——黑白、红白、蓝黄、绿黑；偶尔穿插 1–2 个彩色点缀（主体仍保持高对比）。
- **闪烁频率**：三档基础频率 0.95Hz / 1.4Hz / 2.4Hz（家长可选），游戏中以 ±20% 轻微波动；光栅/棋盘格用平移旋转而非纯闪，避免过度刺激。

## 六、玩法与操作

- 经典贪吃蛇：21×21 网格；吃食物 +10 分、蛇长 +1；撞墙或撞自身游戏结束。
- 食物：高对比圆形/星形随机切换，颜色与当前背景形成强反差。
- 速度曲线：家长可调起始速度（默认中慢），每吃 5 个食物升一档，设速度上限。
- 操作：
  - 键盘：方向键 / WASD。
  - 鼠标：蛇头朝向鼠标位置转向（按住左键锁定跟随）。
  - 触控：本次仅预留接口与 `touch-action` 兼容，不实现操控。

## 七、家长设置面板

覆盖层抽屉，参数如下（全部存入 localStorage 自动记忆）：

- 闪烁频率档位：慢 0.95Hz / 中 1.4Hz / 快 2.4Hz（单选）
- 刺激模式：6 种模式勾选是否参与随机轮换
- 配色模式：高对比 / 混合（高对比主体 + 彩色点缀）
- 起始速度：1–5 档
- 音效：开 / 关
- 背景变化开关：颜色变化 / 形状变化 / 闪烁（各自独立开关）

## 八、音效

- Web Audio API 合成音效（无需音频文件）：吃食物短促"叮"声、游戏结束低音提示。
- 支持一键静音。不做文字鼓励弹窗。

## 九、兼容与平板预留

- 分辨率自适应：棋盘随窗口等比缩放，适配横竖屏与平板比例。
- 触控预留：代码中预留 `touch` 事件接口与扩展注释。
- 不使用外部 CDN、字体、图片资源。
