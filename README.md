# Amblyopia_treatment_game · 弱视治疗训练游戏

面向儿童弱视（Amblyopia）家庭训练的贪吃蛇游戏合集：**遮盖疗法 + 高对比视觉刺激**，以游戏化方式训练注视、追踪与精细目力。纯静态网页，零依赖、离线可用，双击即玩，后续可打包为平板 WebView 应用。

> ⚠️ 本工具为辅助训练软件，**不能替代专业医疗诊断与治疗**。训练方案请遵医嘱；训练前请遮盖好眼，只用弱视眼看。

## 核心功能

- **游戏挑选菜单**：多游戏架构，当前提供贪吃蛇（另有“敬请期待”占位卡片，后续扩展）。
- **贪吃蛇训练**：操控小蛇吃果子，训练注视、扫视与手眼协调。
- **共享背景刺激引擎**：CAM 光栅 / 棋盘格 / 对比条纹三种高对比图案，每 15 秒平滑切换（1 秒淡入淡出）。
- **背景动态变化**：颜色（5–8 秒独立轮换）、形状、闪烁（1.2 / 2 / 3.2 Hz 三档）均可开关、可调节。
- **家长设置**：闪烁档位、刺激模式勾选、操控方式、配色模式、起始速度、音效与背景变化开关，设置自动保存（localStorage）。
- **游戏内菜单**：游戏中按 `Esc`（或暂停按钮）呼出菜单：继续 / 设置 / 重新开始 / 返回游戏列表。
- **自适应布局**：棋盘尺寸随视口缩放并对角收敛，适配手机 / 平板 / 桌面；为平板触控预留扩展点。

## 治疗设计说明

弱视治疗刺激的核心是**高对比度**而非特定颜色：

- **黑白条纹 / 棋盘格（CAM 光栅）**：有临床研究支持（见 PubMed 系统综述 37306731）。
- **近 640nm 红光**：对黄斑锥体刺激有文献支持（以红+白高对比组合保留）。
- **蓝黄互补色**：高对比组合，用于配色轮换，避免长时间单一颜色疲劳。

背景采用高对比配色组轮换：黑白 / 白黑 / 红白 / 蓝黄。建议每次训练 10–15 分钟、每天 1–2 次。

## 使用方法

### 运行

直接双击打开 `index.html` 即可（`file://` 协议，无需联网、无需安装）。

### 操控

- **键盘**：方向键或 `WASD` 转向；空格 / `P` 暂停；`Esc` 打开游戏菜单。
- **鼠标**：移动鼠标或点击棋盘内位置，蛇头朝鼠标方向转向；按住左键锁定跟随。
- **两者**（默认）：键盘与鼠标均可操控，键盘方向键按下时优先接管。

操控方式可在“家长设置 → 操控方式”中切换。

### 家长设置

点击右上角 ⚙ 或游戏菜单中的“设置”打开：

| 设置项 | 说明 |
| --- | --- |
| 闪烁档位 | 慢 1.2Hz / 中 2Hz / 快 3.2Hz（±20% 抖动） |
| 刺激模式 | 勾选参与轮换的模式：CAM 光栅 / 棋盘格 / 对比条纹 |
| 操控方式 | 键盘 / 鼠标 / 两者 |
| 配色模式 | 高对比 / 混合（带彩色点缀） |
| 起始速度 | 1–5 档，适合不同年龄儿童 |
| 背景变化 | 颜色变化 / 形状变化 / 闪烁变化，独立开关 |
| 音效 | 吃到食物、游戏结束音效开关 |

设置即时生效并自动保存，下次打开仍然保留。

## 目录结构

```text
Amblyopia_treatment_game/
├── index.html            # 游戏挑选菜单 + 家长设置 + ?test=1 自测入口
├── css/style.css         # 公共样式（菜单 / HUD / 设置抽屉 / 游戏屏幕）
├── js/bg-engine.js       # 共享背景刺激引擎（模式 / 过渡 / 配色 / 闪烁）
├── js/snake.js           # 贪吃蛇游戏（核心逻辑 + DOM 接线）
├── verify_snake.js       # Node 无头自测
├── acceptance_check.js   # 静态检查 + DOM 桩冒烟验收
└── docs/                 # 设计文档与验收清单
```

## 开发与验证

```bash
node verify_snake.js      # 运行全部纯函数自测
node acceptance_check.js  # 运行静态检查 + 冒烟验收
# 浏览器打开 index.html?test=1 可查看页面内自测横幅
```
